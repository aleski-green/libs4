# libs4

Pinned third-party dependencies for Sapiens4:

- `package.json`, `package-lock.json`: browser libraries and build tools.
- `haskell/`: dependency pins and vendored libsodium.
- `python/`: package requirements and embedded runtime pins.
- `windows/`, `dotnet/`: WebView2 dependency pins.
- `license/`: licenses and dependency notices.

Application code, build configuration and packaging live in Sapiens4.
Do not commit installed dependencies or caches.
